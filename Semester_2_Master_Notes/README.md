## 🎯 Quick Navigation by Topic

### 1. Database Management Systems (`22MCA21`)
* **Module 1**: Three-Schema ANSI/SPARC, Physical & Logical Data Independence, ER Modeling & Relational Schema Mapping.
* **Module 2**: Relational Algebra ($\sigma, \pi, \bowtie$), Nested SQL, Aggregations, Triggers, Views.
* **Module 3**: Functional Dependencies (Armstrong's Axioms), Normalization (1NF, 2NF, 3NF, BCNF step-by-step decomposition).
* **Module 4**: ACID Properties, Conflict Serializability & Precedence Graphs, Two-Phase Locking (2PL), Deadlock Handling.
* **Module 5**: B+ Trees, Storage Organization, NoSQL Systems (MongoDB, Cassandra), CAP Theorem (C vs A vs P).

### 2. Object-Oriented Programming with Java (`22MCA22`)
* **Module 1**: JVM Architecture & Bytecode, Constructors, Garbage Collection, `this` reference.
* **Module 2**: Dynamic Method Dispatch (Runtime Polymorphism), Abstract Classes vs. Interfaces, Packages & Access Modifiers.
* **Module 3**: Checked vs. Unchecked Exceptions, Custom Exceptions, Multithreading Lifecycle, Producer-Consumer Synchronization (`wait()` / `notify()`).
* **Module 4**: Java Collections Framework (`ArrayList`, `HashSet`, `HashMap`), Generics, Lambdas, Streams API.
* **Module 5**: JDBC 7-step connectivity, `PreparedStatement`, `ResultSet`, Transaction handling, File I/O Serialization.

### 3. Software Engineering & Agile Methodology (`22MCA23`)
* **Module 1**: Waterfall vs. Spiral vs. V-Model, Agile Manifesto, Scrum Framework (Roles, Artifacts, Ceremonies).
* **Module 2**: Requirements Engineering, Functional vs. Non-Functional, IEEE 830 Standard for SRS, User Stories.
* **Module 3**: UML 2.0 Diagrams (Use Case, Class, Sequence, Activity), Layered vs. Microservices Architecture.
* **Module 4**: Testing Levels (Unit, Integration, System, Acceptance), Boundary Value Analysis (BVA), Cyclomatic Complexity ($V(G) = D + 1$).
* **Module 5**: COCOMO II Estimation Model, Risk Management (RMMM Plan), DevSecOps CI/CD Automation.

### 4. Web Technologies & Application Development (`22MCA24`)
* **Module 1**: HTML5 Semantic Markup, CSS3 Flexbox Centering, CSS Grid Two-Dimensional layouts, Media Queries.
* **Module 2**: JavaScript ES6+ (Hoisting, Closures, Promises, `async`/`await`, Fetch API, DOM manipulation).
* **Module 3**: React.js Architecture, Virtual DOM Diffing, JSX, React Hooks (`useState`, `useEffect`), State vs Props.
* **Module 4**: Node.js Event Loop, Express.js Middleware, Building RESTful API Endpoints (GET, POST, PUT, DELETE).
* **Module 5**: Full-Stack MERN Integration, MongoDB Mongoose ODM, JWT Token Authentication, Web Security (XSS, CSRF, CORS).

### 5. Cloud Computing & DevOps (`22MCA25`)
* **Module 1**: NIST 5 Essential Characteristics, IaaS vs PaaS vs SaaS, Shared Responsibility Model.
* **Module 2**: Type 1 vs Type 2 Hypervisors, Containers vs VMs, Multi-Stage Production `Dockerfile`, Docker Compose.
* **Module 3**: Kubernetes Cluster Architecture (Control Plane vs Worker Nodes), Pods, Deployments, Services (ClusterIP, NodePort, LoadBalancer).
* **Module 4**: AWS Global Infrastructure, VPC, Public/Private Subnets, EC2, S3 Storage Classes, IAM, Lambda Serverless.
* **Module 5**: Infrastructure as Code (Terraform), GitHub Actions CI/CD Pipeline YAML, Trivy Security Scans, Prometheus/Grafana.
