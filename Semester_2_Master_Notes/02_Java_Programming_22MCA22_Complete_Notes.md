# MODULE 1: JAVA ARCHITECTURE & OOP BASICS

## 1.1 JVM, JRE, and JDK Architecture
* **Bytecode**: Intermediate, platform-independent code generated by `javac` compiler (`.class` files).
* **JVM (Java Virtual Machine)**: Abstract computing machine that executes bytecode. Translates bytecode into native machine code via **JIT (Just-In-Time) Compiler**.
* **JRE (Java Runtime Environment)**: Contains JVM + core runtime class libraries (e.g., `java.lang`, `java.util`).
* **JDK (Java Development Kit)**: Contains JRE + development tools (`javac`, `javadoc`, `jdb`, `jar`).

---

## 1.2 Constructors and Memory Allocation
* **Constructor**: A special method invoked when an object is instantiated via `new`. Has no return type and same name as class.
* **`this` Keyword**: A reference to the current invoking object:
  1. Resolves variable shadowing between instance fields and local parameters.
  2. Invokes another constructor in the same class: `this(arg1, arg2)` (**Constructor Chaining**; must be first statement).

# MODULE 2: INHERITANCE & INTERFACES

## 2.1 Dynamic Method Dispatch (Runtime Polymorphism)
A mechanism where a call to an overridden method is resolved at runtime rather than compile time.
```java
class Shape {
    void draw() { System.out.println("Drawing generic shape"); }
}
class Circle extends Shape {
    @Override
    void draw() { System.out.println("Drawing circle with radius r"); }
}
class Square extends Shape {
    @Override
    void draw() { System.out.println("Drawing square with side s"); }
}

public class TestPolymorphism {
    public static void main(String[] args) {
        Shape s; // Superclass reference variable
        s = new Circle();
        s.draw(); // Output: Drawing circle with radius r

        s = new Square();
        s.draw(); // Output: Drawing square with side s
    }
}
```

## 2.2 Abstract Class vs. Interface

| Feature | Abstract Class | Interface |
| :--- | :--- | :--- |
| **Methods** | Can have abstract, concrete, and final methods | Prior to Java 8, strictly abstract. Java 8+ allows `default` and `static` methods |
| **Variables** | Can have instance variables with any modifier | Variables are implicitly `public static final` constants |
| **Inheritance** | Single inheritance (`extends`) | Multiple inheritance supported (`implements`) |
| **Constructors** | Can declare constructors | Cannot declare constructors |
| **Speed** | Slightly faster method invocation | Requires dynamic search in interface table |

# MODULE 3: EXCEPTION HANDLING & MULTITHREADING

## 3.1 Exception Hierarchy
* Root: `java.lang.Throwable`
  * `java.lang.Error`: Fatal system failures not meant to be caught (e.g., `OutOfMemoryError`, `StackOverflowError`).
  * `java.lang.Exception`: Conditions that an application can recover from.
    * **Checked Exceptions**: Verified at compile time. Must be declared in `throws` or wrapped in `try-catch` (e.g., `IOException`, `SQLException`, `ClassNotFoundException`).
    * **Unchecked Exceptions (`RuntimeException`)**: Occur during execution due to logical programming errors (e.g., `NullPointerException`, `ArrayIndexOutOfBoundsException`, `ArithmeticException`).

---

## 3.2 Thread Synchronization & Inter-Thread Communication
Synchronization prevents thread interference and race conditions on shared objects using internal object **Monitors / Locks**.

### Producer-Consumer Implementation using `wait()` and `notify()`:
```java
class SharedBuffer {
    private int data;
    private boolean available = false;

    public synchronized void produce(int value) throws InterruptedException {
        while (available) {
            wait(); // Release lock and wait for consumer
        }
        data = value;
        available = true;
        System.out.println("Produced: " + data);
        notify(); // Wake up waiting consumer
    }

    public synchronized int consume() throws InterruptedException {
        while (!available) {
            wait(); // Release lock and wait for producer
        }
        available = false;
        System.out.println("Consumed: " + data);
        notify(); // Wake up waiting producer
        return data;
    }
}
```

# MODULE 4: COLLECTIONS FRAMEWORK & STREAMS

## 4.1 Collection Framework Hierarchy
* `List` (Ordered, duplicates allowed): `ArrayList` (contiguous array, $O(1)$ read), `LinkedList` (doubly linked, $O(1)$ insert/delete).
* `Set` (No duplicates): `HashSet` ($O(1)$ hash table), `TreeSet` (sorted Red-Black tree, $O(\log n)$).
* `Map` (Key-Value pairs): `HashMap` (unsorted), `TreeMap` (sorted keys), `ConcurrentHashMap` (thread-safe segment locking).

## 4.2 Stream API Operations
```java
List<String> names = Arrays.asList("Anand", "Basavaraj", "Vijay", "Anita", "Pooja");

// Filter names starting with 'A', transform to uppercase, and collect
List<String> result = names.stream()
                           .filter(s -> s.startsWith("A"))
                           .map(String::toUpperCase)
                           .sorted()
                           .collect(Collectors.toList());
// result: ["ANAND", "ANITA"]
```

# MODULE 5: JDBC & FILE I/O

## 5.1 The 7 Standard Steps of JDBC
```java
import java.sql.*;

public class JdbcExamDemo {
    public static void main(String[] args) {
        String url = "jdbc:mysql://localhost:3306/vtu_mca_db";
        String user = "root";
        String pass = "password123";

        // Step 1: Load and register JDBC driver (optional in modern JDBC 4.0+)
        // Class.forName("com.mysql.cj.jdbc.Driver");

        // Step 2 & 3: Establish Connection and prepare statement
        String sql = "INSERT INTO Students (usn, name, gpa) VALUES (?, ?, ?)";
        try (Connection conn = DriverManager.getConnection(url, user, pass);
             PreparedStatement pstmt = conn.prepareStatement(sql)) {

            // Step 4: Set parameter values
            pstmt.setString(1, "3RB24MC001");
            pstmt.setString(2, "Sunil Kumar");
            pstmt.setDouble(3, 8.92);

            // Step 5: Execute update
            int rowsAffected = pstmt.executeUpdate();
            System.out.println("Rows inserted: " + rowsAffected);

            // Step 6: Query data using Statement & ResultSet
            Statement stmt = conn.createStatement();
            ResultSet rs = stmt.executeQuery("SELECT usn, name, gpa FROM Students");
            while (rs.next()) {
                System.out.println(rs.getString("usn") + " | " + 
                                   rs.getString("name") + " | " + 
                                   rs.getDouble("gpa"));
            }
        } catch (SQLException e) {
            e.printStackTrace();
        }
    }
}
```

# 🎯 Model Exam Questions with Step-by-Step Solutions

### Q1. [Module 3 - 10 Marks]
**Write a complete Java program defining a custom checked exception `InvalidAgeException`. A method `checkEligibility(int age)` throws this exception if age is less than 18. Demonstrate handling in `main()`.**

**Solution:**
```java
// Step 1: Define Custom Checked Exception extending Exception
class InvalidAgeException extends Exception {
    public InvalidAgeException(String message) {
        super(message);
    }
}

public class AgeVerificationApp {
    // Step 2: Method declaring exception via throws keyword
    static void checkEligibility(int age) throws InvalidAgeException {
        if (age < 18) {
            throw new InvalidAgeException("Access Denied: Age " + age + " is below legal requirement 18.");
        } else {
            System.out.println("Access Granted: Welcome to the portal!");
        }
    }

    public static void main(String[] args) {
        int testAges[] = {21, 15, 19};

        for (int age : testAges) {
            try {
                System.out.println("Checking age: " + age);
                checkEligibility(age);
            } catch (InvalidAgeException ex) {
                System.err.println("Caught Exception: " + ex.getMessage());
            } finally {
                System.out.println("Verification check completed for candidate.\n");
            }
        }
    }
}
```
