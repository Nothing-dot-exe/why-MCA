# 1. 🗄️ Database Management Systems (`22MCA21` / `MMC103`)

* **[Gate Smashers - DBMS Complete Playlist](https://www.youtube.com/playlist?list=PLxCzCOWd7aiFAN6I8C9azFc51AK384BrU)**
  * **Topics**: ER Diagram notations, ER to Relational mapping, Relational Algebra operators ($\sigma, \pi, \bowtie$), **Functional Dependencies & BCNF Normalization numericals**, ACID properties, Conflict Serializability & Precedence Graphs, Two-Phase Locking (2PL).
* **[Knowledge Gate - DBMS by Sanchit Jain](https://www.youtube.com/@KnowledgeGate_KGS)**: Best for in-depth understanding of Concurrency Control and B+ Trees.

# 2. ☕ Java Programming (`22MCA22` / `MMC202`)

* **[Telusko - Core Java Complete Course](https://www.youtube.com/playlist?list=PLsyeobzWxl7pe_IiTfNyr55kwJPWbgxB5)**
  * **Topics**: JVM architecture, Constructors, Dynamic Method Dispatch (Runtime Polymorphism), Abstract classes vs. Interfaces, Exception Handling, Thread Lifecycle & Synchronization (`wait()` / `notify()`), Collections Framework, and JDBC connections.
* **[Kunal Kushwaha - Java OOP Deep Dive](https://www.youtube.com/playlist?list=PL9gnSGHSqcnr_DxHsP7AW9ftq0AtAyYqJ)**: Exceptional visual clarity on OOP principles, memory allocation, and generics.

# 3. 🛠️ Software Engineering & Agile Methodology (`22MCA23` / `MMC204`)

* **[Gate Smashers - Software Engineering Playlist](https://www.youtube.com/playlist?list=PLxCzCOWd7aiEed7SKZBnC6ypFDWYLRvB2)**
  * **Topics**: Waterfall vs. Spiral vs. Agile, Scrum ceremonies and roles, SRS IEEE 830 standard, UML Diagrams, **Cyclomatic Complexity calculation ($V(G) = D + 1$)**, Boundary Value Analysis (BVA), and COCOMO II cost estimation.
* **[TechWorld with Nana - Agile & Scrum Explained](https://www.youtube.com/@TechWorldwithNana)**: Quick practical video explaining how real tech teams run Agile sprints.
