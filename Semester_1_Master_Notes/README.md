## 🎯 Quick Navigation by Topic

### 1. Mathematical Foundations (`22MCA11`)
* **Module 1**: Principle of Inclusion-Exclusion (3-set proof), Equivalence Relations, POSET.
* **Module 2**: Gauss Elimination, Rank of Matrix, Characteristic Equation, Eigenvalues & Eigenvectors, Cayley-Hamilton.
* **Module 3**: Graph Theory, Handshaking Lemma, Euler vs Hamiltonian, Prim's and Kruskal's MST.
* **Module 4**: Bayes' Theorem, Conditional Probability, Binomial, Poisson, and Normal Distributions.
* **Module 5**: Hypothesis Testing, Type I & II errors, Large sample $Z$-test, Small sample $t$-test, $\chi^2$ independence test.

### 2. Operating Systems (`22MCA12`)
* **Module 1**: Dual-Mode CPU execution (User/Kernel), System Calls, Process Lifecycle, PCB, `fork()`, `exec()`, `wait()`.
* **Module 2**: CPU Scheduling (FCFS, SJF Preemptive, Round Robin Gantt charts), Critical Section Problem, Peterson's Solution, Semaphores.
* **Module 3**: Deadlocks (4 Coffman conditions), Banker's Safety & Request Algorithm, Paging & Page Tables, TLB, Effective Access Time.
* **Module 4**: Virtual Memory, Page Fault handling, Page Replacement Algorithms (FIFO, Belady's Anomaly, LRU, Optimal).
* **Module 5**: Disk Scheduling (FCFS, SSTF, SCAN, C-SCAN, LOOK), RAID levels, Linux file permissions (`chmod`), Bash shell scripting.

### 3. Data Structures with Algorithms (`22MCA13`)
* **Module 1**: Stack LIFO, Infix-to-Postfix conversion, Postfix evaluation, Circular Queue modulo arithmetic.
* **Module 2**: Singly Linked List (insertion, deletion, reversal), Doubly Linked List, Circular Linked List.
* **Module 3**: Binary Trees, Traversals (Inorder, Preorder, Postorder, Level-Order), Binary Search Tree (BST) insertion, search & 3 deletion cases.
* **Module 4**: AVL Trees (Balance Factor, LL, RR, LR, RL rotations), Hashing (Division, Mid-square), Collision Resolution (Chaining vs Open Addressing).
* **Module 5**: Graph BFS & DFS traversals, Sorting (Merge, Quick, Heap) comparison and stability table.

### 4. Computer Networks (`22MCA14`)
* **Module 1**: OSI 7-Layer vs TCP/IP 4-Layer architecture, Framing & Bit Stuffing, CRC Error Detection (Modulo-2 polynomial division).
* **Module 2**: Sliding Window ARQ (Go-Back-N vs Selective Repeat), CSMA/CD Ethernet (collision detection, backoff), CSMA/CA Wi-Fi.
* **Module 3**: IPv4 Subnetting & CIDR calculations (/26, /27, network ID, host range, broadcast address), Distance Vector vs Link State Routing, ARP, NAT.
* **Module 4**: TCP vs UDP, TCP 3-Way Handshake & 4-Way Teardown, TCP Congestion Control (Slow Start, Congestion Avoidance, Fast Retransmit).
* **Module 5**: DNS, HTTP/HTTPS, runnable Python TCP Socket Client-Server implementation.

### 5. Design and Analysis of Algorithms (`22MCA15`)
* **Module 1**: Asymptotic Notations ($O, \Omega, \Theta$ formal definitions), Master Theorem for divide-and-conquer recurrences.
* **Module 2**: Divide & Conquer, Merge Sort ($O(n \log n)$), Quick Sort (Lomuto partition, best/worst analysis), Strassen's Matrix Multiplication.
* **Module 3**: Greedy Method, Fractional Knapsack, Dijkstra's Shortest Path, Prim's and Kruskal's MST, Huffman Coding.
* **Module 4**: Dynamic Programming, Principle of Optimality, 0/1 Knapsack full table trace and backtrace, Floyd-Warshall ($O(V^3)$), Matrix Chain Multiplication.
* **Module 5**: Backtracking, State-Space Tree, N-Queens Problem, Branch and Bound, Theory of NP-Completeness (P, NP, NP-Complete, NP-Hard, Cook's Theorem).

## 🏆 Scoring Strategy for VTU Exams & CIE at BKIT Bhalki
1. **Continuous Internal Evaluation (CIE)**:
   * Target **40+/50 marks**.
   * Always write step-by-step solutions for tests, including formulas, state diagrams, and tables.
2. **Semester End Examination (SEE)**:
   * The VTU question paper provides choice: **Answer 5 full questions**, choosing one from each module.
   * Numerical questions (e.g., *Banker's Algorithm, CRC division, CIDR subnetting, Eigenvalues, 0/1 Knapsack, Infix-to-Postfix*) award full $10/10$ marks if steps and arithmetic are accurate. Always prioritize these over pure essay questions.
