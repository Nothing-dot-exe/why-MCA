# Technical Mock Interview Simulator & Evaluation Rubric

Use this scorecard when conducting self-practice or peer mock interviews.

---

## 📊 100-Point Technical Interview Rubric

| Evaluation Area | Weight | Poor (1-2 pts) | Good (3-4 pts) | Exceptional (5 pts) |
| :--- | :--- | :--- | :--- | :--- |
| **1. Problem Exploration & Clarification** | 15% | Jumps immediately to code without asking questions. | Clarifies inputs, outputs, and basic scale. | Asks clarifying questions on constraints, edge cases (null, empty, negative), scale, and memory limits before writing a single line. |
| **2. Algorithm Design & Pattern Recognition** | 25% | Proposes inefficient brute force and gets stuck. | Identifies working approach with small hints. | Clearly articulates optimal pattern (e.g. Sliding Window, Min-Heap), explains trade-offs, and verifies with a dry run. |
| **3. Code Quality & Clean Implementation** | 25% | Syntactically buggy, poor variable names (`a, b, x`). | Working code with minor style flaws. | Modular, clean, production-grade code with idiomatic naming, proper error handling, and zero off-by-one errors. |
| **4. Time & Space Complexity Analysis** | 15% | Incorrect Big-O or guesses without justification. | Correctly states time/space complexity. | Formally proves Big-O Time & Space complexities, including recursion call stack and auxiliary memory. |
| **5. Communication & Thought Process** | 20% | Stays silent for minutes; defensive when nudged. | Explains code while typing when asked. | Speaks thoughts out loud continuously, receives interviewer hints constructively, and conducts structured self-testing. |

---

## ⏱️ The 45-Minute Interview Timer Breakdown
* **00:00 – 05:00**: Introductions & Resume pitch (Elevator pitch).
* **05:00 – 10:00**: Problem statement reading, clarification of constraints & test cases.
* **10:00 – 15:00**: High-level algorithm proposal, dry-run on whiteboard, Big-O trade-offs.
* **15:00 – 35:00**: Writing clean, optimal code while talking through logic.
* **35:00 – 40:00**: Self-testing with normal, edge-case, and boundary test cases.
* **40:00 – 45:00**: Interviewer follow-up questions & questions for the interviewer.
