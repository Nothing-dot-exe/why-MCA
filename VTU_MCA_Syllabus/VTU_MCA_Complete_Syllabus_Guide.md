SEMESTER 1: SYLLABUS BREAKDOWN (RECENT VS LAST YEAR)
================================================================================

1. MATHEMATICAL FOUNDATIONS FOR COMPUTER APPLICATIONS
* Codes: 24MCA11 (Recent Year) | 22MCA11 / 20MCA11 (Last Years)
* Credits: 4 (Lecture: 3 hrs/week, Tutorial: 2 hrs/week)
* Module 1: Set Theory & Relations
  - Sets, Subsets, Power sets, Venn diagrams, Cartesian products.
  - Relations: Reflexive, Symmetric, Transitive, Equivalence Relations.
  - Principle of Inclusion and Exclusion (Formula, 3-set proof, Combinatorics).
* Module 2: Matrix Algebra & Linear Systems
  - Determinants, Rank of a Matrix, Consistency of linear equations.
  - Gauss-Elimination and Gauss-Jordan Methods.
  - Eigenvalues and Eigenvectors, Cayley-Hamilton Theorem, Matrix Diagonalization.
* Module 3: Graph Theory & Combinatorics
  - Graph terminology, Handshaking Lemma (Proof & application to degrees).
  - Eulerian and Hamiltonian paths/cycles, Isomorphism.
  - Trees, Spanning Trees, Prim's and Kruskal's MST Algorithms.
* Module 4: Probability Theory & Random Variables
  - Axioms of probability, Conditional probability, Law of Total Probability.
  - Bayes' Theorem (Spam detection, medical diagnostics examples).
  - Discrete & Continuous random variables, PMF, PDF, Binomial, Poisson, Normal distributions.
* Module 5: Statistical Inference & Testing
  - Null vs Alternative Hypothesis, Type I (Alpha) and Type II (Beta) errors.
  - Large sample Z-tests, Small sample Student's t-test, Chi-Square test for independence.

--------------------------------------------------------------------------------
2. OPERATING SYSTEM CONCEPTS & LINUX
* Codes: 24MCA12 (Recent Year) | 22MCA12 / 20MCA12 (Last Years)
* Credits: 4
* Module 1: OS Architecture & Process Management
  - Kernel services, Dual-Mode CPU execution (User vs Kernel Mode, Trap handlers).
  - Process Control Block (PCB), Context Switching, Operations: fork(), exec(), wait(), exit().
* Module 2: CPU Scheduling & Synchronization
  - FCFS, SJF (Preemptive/Non-preemptive), Round Robin, Priority Scheduling Gantt charts.
  - Critical Section Problem, Peterson's Algorithm, Mutex, Semaphores (Producer-Consumer).
* Module 3: Deadlocks & Memory Management
  - 4 Coffman Conditions, Resource Allocation Graphs, Banker's Safety Algorithm.
  - Logical vs Physical Address Space, Paging, Page Tables, Segmentation.
* Module 4: Virtual Memory & Page Replacement
  - Demand Paging, Page Fault interrupt mechanism, Page Replacement: FIFO, Optimal, LRU.
* Module 5: Storage Architecture & Linux Shell
  - Disk Scheduling: FCFS, SSTF, SCAN, C-SCAN, LOOK. RAID levels (0, 1, 5, 10).
  - Linux Architecture, Bash shell programming, Process monitoring (ps, top, kill).

--------------------------------------------------------------------------------
3. DATA STRUCTURES AND ALGORITHMS
* Codes: 24MCA13 (Recent Year) | 22MCA13 / 20MCA13 (Last Years)
* Credits: 4
* Module 1: Stacks & Queues (Linear Structures)
  - Stack ADT, Infix to Postfix conversion stack trace, Postfix evaluation.
  - Circular Queue, Deque, Priority Queue implementations in C/Python.
* Module 2: Linked Lists
  - Singly, Doubly, and Circular Linked Lists (Insertion, Deletion, Reversal).
* Module 3: Trees & Binary Search Trees (BST)
  - Binary Trees, Traversals (Inorder, Preorder, Postorder, Level-Order).
  - BST Operations: Insert, Delete, Search, Height calculation.
* Module 4: Balanced Trees & Hashing
  - AVL Trees: LL, RR, LR, RL Rotations, B-Trees, B+ Trees.
  - Hashing: Collision resolution by Chaining, Linear & Quadratic Probing.
* Module 5: Graphs & Sorting
  - BFS, DFS, Sorting: Merge Sort, Quick Sort, Heap Sort analysis.

--------------------------------------------------------------------------------
4. COMPUTER NETWORKS
* Codes: 24MCA14 (Recent Year) | 22MCA14 / 20MCA14 (Last Years)
* Credits: 4
* Module 1: Physical & Data Link Layer
  - OSI 7-Layer vs TCP/IP 4-Layer model, Framing, CRC error detection calculations.
* Module 2: MAC Layer Protocols
  - CSMA/CD, CSMA/CA, Ethernet 802.3, Wi-Fi 802.11 standards.
* Module 3: Network Layer & IP Addressing
  - Routing: Dijkstra Shortest Path, Link State (OSPF), Distance Vector.
  - IPv4 Subnetting calculations (CIDR /26, /27), NAT, ARP, IPv6 transition.
* Module 4: Transport Layer
  - TCP vs UDP, TCP 3-Way Handshake, 4-Way Connection Teardown, Congestion Control.
* Module 5: Application Layer & Socket Programming
  - DNS, HTTP/HTTPS, TLS/SSL, Python Socket Programming for TCP Echo Client-Server.

--------------------------------------------------------------------------------
5. DESIGN AND ANALYSIS OF ALGORITHMS
* Codes: 24MCA15 (Recent Year) | 22MCA15 / 20MCA15 (Last Years)
* Credits: 4
* Module 1: Asymptotic Notations & Recurrences (Big-O, Omega, Theta, Master Theorem).
* Module 2: Divide & Conquer (Merge Sort, Quick Sort, Strassen Matrix Multiplication).
* Module 3: Greedy Algorithms (Fractional Knapsack, Prim/Kruskal MST, Dijkstra).
* Module 4: Dynamic Programming (0/1 Knapsack, Floyd-Warshall, Matrix Chain, LCS).
* Module 5: Backtracking & NP-Completeness (N-Queens, Graph Coloring, P vs NP).
