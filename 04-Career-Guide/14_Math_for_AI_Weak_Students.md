## 📐 Pillar 1 — Linear Algebra

**Why it matters:**
- Images = Matrix of pixel values
- Words = Vectors in space
- Neural networks = Matrix multiplications
- ChatGPT is basically GIANT matrix math!

### What to Learn

**Level 1 — Basics (Week 1–2):**
- Vector: Just a list of numbers! `[1, 2, 3]`
- Matrix: A table of numbers (rows × columns) — like Excel!
- Operations: Add, multiply, dot product

**Level 2 — Important (Week 3–4):**
- Matrix multiplication (how neural network layers connect)
- Transpose, Identity matrix, Determinant

**Level 3 — Useful (Week 5–6):**
- Eigenvalues & Eigenvectors (used in PCA)
- SVD (used in Netflix recommendations!)

## 🔢 Pillar 3 — Calculus

> **Good News:** You don't need calculus to USE AI — only to UNDERSTAND and BUILD from scratch. Libraries (PyTorch, TensorFlow) do calculus automatically!

### Simple Analogy — Gradient Descent

> 🏔️ **Intuitive Analogy — Gradient Descent:**
> - Imagine you are blindfolded on hilly terrain, trying to find the lowest valley floor.
> - At each step, you feel with your feet which direction slopes downhill.
> - You take a measured step in that downward direction.
> - You repeat this process iteratively until the ground levels out at the bottom.
> 
> *That is precisely what an AI model does mathematically to minimize error and loss during training!*

### What to Learn

**Level 1 — Concepts (Week 1–2):**
- What is a function? `f(x) = x²`
- What is a slope/gradient? (How steep is the hill?)
- Derivative = rate of change

**Level 2 — AI-Specific (Week 3–4):**
- Derivatives of simple functions
- **Chain rule** ← Most important for AI!
- Partial derivatives (multiple variables)

**Level 3 — Deep Learning (Week 5–6):**
- Gradient Descent algorithm
- Backpropagation intuition
- Learning rate concept

## 🎲 Pillar 4 — Probability

**Why it matters:**
- AI outputs probabilities: "Cat image: 92% cat, 7% dog, 1% other"
- Spam filter: "97% chance this is spam"

### What to Learn

**Level 1 — Basics (Week 1):**
- P(event) between 0 and 1
- `P(coin heads) = 0.5 = 50%`
- Addition, multiplication, complement rules

**Level 2 — Important (Week 2–3):**
- Conditional Probability `P(A|B)` ← Critical for AI!
- Bayes Theorem ← VERY important!
  - Used in: Spam filters, medical AI, classification

**Level 3 — ML-Specific (Week 4):**
- Probability Distributions (Bernoulli, Gaussian)
- Maximum Likelihood Estimation (MLE)
- Entropy & Information Theory (used in Decision Trees!)

## 🐍 The Secret Weapon — Learn Math Through Python!

**Instead of memorizing → CODE it! See results instantly!**

```python
import numpy as np

# Statistics in 1 minute
data = [10, 20, 30, 40, 50]
print("Mean:", np.mean(data))       # 30.0
print("Std Dev:", np.std(data))     # 14.14
print("Median:", np.median(data))   # 30.0

# Matrix multiplication
A = np.array([[1, 2], [3, 4]])
B = np.array([[5, 6], [7, 8]])
print("A × B =\n", np.dot(A, B))
# [[19 22]
#  [43 50]]
```
