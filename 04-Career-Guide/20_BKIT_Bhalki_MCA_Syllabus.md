## 🏛️ Syllabus Governance at BKIT Bhalki

**Bheemanna Khandre Institute of Technology (BKIT)** is an affiliated engineering college under **Visvesvaraya Technological University (VTU)**.
- Under VTU statutes, all affiliated institutions follow the **Centralized VTU MCA Curriculum & Examination Regulations**.
- The examination question papers are set directly by VTU Belagavi, and evaluations are moderated under the **VTU Regional Center, Kalaburagi**.
- **Total Program Credits:** **80 Credits** across 4 Semesters (approx. 20 credits per semester).
- **Grading Pattern:** 10-Point CGPA scale.
- **Evaluation Pattern:** Split into **Continuous Internal Evaluation (CIE)** conducted at BKIT and **Semester End Examination (SEE)** conducted by VTU.

### Module-Wise Breakdown (Semester 1)

#### 1. 22MCA11: Mathematical Foundation for Computer Applications
- **Module 1 (Mathematical Logic):** Propositions, Logical Connectives, Truth Tables, Tautology, Contradiction, Logical Equivalence, De Morgan's Laws, Predicates, and Quantifiers ($\forall, \exists$).
- **Module 2 (Set Theory & Relations):** Sets, Power Sets, Cartesian Product, Relations, Equivalence Relations, Equivalence Classes, Posets, and Hasse Diagrams.
- **Module 3 (Functions & Matrices):** Injective, Surjective, Bijective functions, Inverse functions, Matrix operations, Determinants, Matrix Inversion, Systems of Linear Equations, Eigenvalues & Eigenvectors.
- **Module 4 (Graph Theory):** Basic definitions, Degree of vertices, Handshaking Lemma, Paths, Cycles, Bipartite Graphs, Eulerian & Hamiltonian Graphs, Trees, Adjacency & Incidence Matrices, Planar Graphs, Euler's Formula ($V - E + F = 2$).
- **Module 5 (Probability & Statistics):** Sample spaces, Axioms of probability, Conditional probability, Law of Total Probability, Bayes' Theorem, Random variables, Mean, Variance, Binomial and Normal distributions.

#### 2. 22MCA12: Operating System Concepts
- **Module 1:** Introduction to Operating Systems, Dual-Mode Operations (Kernel vs User), System Calls, Process Concepts, Process States, PCB, Context Switching, Inter-Process Communication (IPC).
- **Module 2:** CPU Scheduling: Criteria, Preemptive vs Non-Preemptive, FCFS, SJF, SRTF, Round Robin (RR), Priority Scheduling, Multi-Level Queue Scheduling.
- **Module 3:** Process Synchronization: Race Conditions, Critical Section Problem, Peterson's Algorithm, Semaphores (Counting and Binary), Mutex Locks, Classic IPC Problems (Producer-Consumer, Dining Philosophers).
- **Module 4:** Deadlocks: 4 Coffman Conditions, Resource Allocation Graphs (RAG), Deadlock Prevention, Avoidance with Banker's Algorithm, Deadlock Detection and Recovery.
- **Module 5:** Memory Management: Contiguous Allocation, Paging, Page Tables, TLB Cache, Segmentation, Virtual Memory, Demand Paging, Page Fault Handling, Page Replacement Algorithms (FIFO, LRU, Optimal), Thrashing.

#### 3. 22MCA13: Data Structures with Algorithms
- **Module 1:** Asymptotic Analysis (Big-$O$, $\Omega$, $\Theta$), Array operations, Stacks (Array and Pointer representations, Infix to Postfix conversion, Postfix evaluation).
- **Module 2:** Queues: Linear Queue, Circular Queue, Deque, Priority Queue.
- **Module 3:** Linked Lists: Singly Linked List, Doubly Linked List, Circular Linked List, Linked List reversal, Polynomial Addition.
- **Module 4:** Trees: Binary Trees, Binary Search Trees (BST), Tree Traversals (Inorder, Preorder, Postorder), AVL Trees (Rotations: LL, RR, LR, RL), B-Trees.
- **Module 5:** Graphs: Adjacency representations, BFS, DFS, Dijkstra's Shortest Path, Prim's and Kruskal's Minimum Spanning Tree (MST).

#### 4. 22MCA14: Computer Networks
- **Module 1:** Physical Layer, Topologies (Star, Mesh, Ring, Bus), OSI 7-Layer Model vs TCP/IP Protocol Suite, Transmission Media.
- **Module 2:** Data Link Layer: Framing, Error Detection (Parity, Checksum, CRC Modulo-2 Division), Flow Control (Stop-and-Wait, Sliding Window, Go-Back-N, Selective Repeat), CSMA/CD.
- **Module 3:** Network Layer: IPv4 Addressing, Subnetting & CIDR calculations, IPv6, NAT, ARP, Routing Algorithms (Distance Vector Bellman-Ford, Link State Dijkstra).
- **Module 4:** Transport Layer: UDP vs TCP, TCP 3-Way Handshake, TCP 4-Way Teardown, Flow Control, Congestion Control (Slow Start, AIMD).
- **Module 5:** Application Layer: DNS, HTTP/HTTPS, SMTP, Firewalls (Packet Filtering, Stateful Inspection), SSL/TLS Cryptographic Handshake.

#### 5. 22MCAL16 & 22MCAL17: Practical Laboratories
- **Lab 1 (DSA):** C/C++ implementations of Stacks, Queues, Circular Queues, Linked Lists, BST insertion/traversal, AVL tree rotations, Dijkstra's algorithm.
- **Lab 2 (OS & Networking):** Linux bash shell scripting, Process creation using `fork()`, CPU scheduling simulation in C (FCFS/SJF/RR), Banker's algorithm implementation, Socket programming in C (Client-Server TCP/UDP).

### Key Highlights (Semester 2)
- **22MCA21 (DBMS):** Relational Algebra, SQL (DDL, DML, TCL, Joins, Triggers, Stored Procedures), Functional Dependencies, Normal Forms (**1NF, 2NF, 3NF, BCNF**), ACID Transactions, Serializability, Two-Phase Locking (2PL), Crash Recovery (WAL, Checkpoints).
- **22MCA22 (Java):** JVM Architecture, Bytecode, Encapsulation, Inheritance, Dynamic Method Dispatch (Runtime Polymorphism), Abstract Classes vs Interfaces, Custom Exceptions, Multithreading & Synchronization, Collections Framework (`ArrayList`, `HashMap`, `TreeSet`).
- **22MCA23 (Software Engineering):** Software Process Models (Waterfall, Spiral, Agile Scrum, Kanban), Requirement Engineering, UML Diagrams (Use Case, Class, Sequence), Software Testing (Black-Box vs White-Box).
- **22MCA24 (Web Technologies):** HTML5 Semantic Elements, CSS3 Flexbox & Grid, JavaScript ES6+ (Arrow Functions, Closures, Promises, `async/await`), DOM Manipulation, Form Validation with Regular Expressions, REST APIs.
